## ⚙️ Getting Started

Run the portfolio locally in a few steps:

```bash
# 1. Clone the repository
git clone https://github.com/prethul/My_Portfolio.git

# 2. Move into the project folder
cd My_Portfolio

# 3. Open index.html in your browser
#    or use a local server (recommended):
npx serve .
```

## 🌍 Deployment

This site is deployed on **Netlify** with automatic deploys on every push to the main branch.

1. Push your changes to GitHub
2. Netlify detects the commit and rebuilds
3. The live site updates at **[diptoprethul.netlify.app](https://diptoprethul.netlify.app/)**
